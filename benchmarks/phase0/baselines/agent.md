# Neutral Agent baseline instructions

Audit the supplied single-cell artifact against the declared scientific question. Inspect only the
provided read-only evidence. Do not use the network, infer missing facts, or execute declared
project analysis scripts. Return the required structured output with a decision of `pass`, `fail`,
or `indeterminate`, detected failure families, concise evidence, remediation, and any abstention
reason. A successful file read or script-shaped project is not evidence that an analysis was
executed correctly.
